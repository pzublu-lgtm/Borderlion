# Portfolio Website

This project is a personal portfolio website that showcases various projects, research, and insights into textile philosophies. It features a unique design with a Digimon-like character and an AI assistant chatbox for user interaction.

## Features

- **Homepage**: A visually striking black screen with a central character and an interactive chatbox.
- **Navigation**: Easy access to different sections including Projects, Research, Contact, and Textile Philosophies.
- **Projects Grid**: A display of various projects with links for more details.
- **Research List**: A compilation of research topics and papers.
- **Contact Form**: A simple form for users to reach out.
- **Textile Philosophy**: Insights and information about textile philosophies.

## Technologies Used

- React
- TypeScript
- CSS

## Setup Instructions

1. Clone the repository:
   ```
   git clone <repository-url>
   ```

2. Navigate to the project directory:
   ```
   cd portfolio-website
   ```

3. Install dependencies:
   ```
   npm install
   ```

4. Start the development server:
   ```
   npm start
   ```

5. Open your browser and go to `http://localhost:3000` to view the website.

## Usage

- Interact with the AI assistant through the chatbox.
- Navigate through the portfolio sections using the navigation menu.
- Explore projects and research topics to learn more about the work.
